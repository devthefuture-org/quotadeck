## One glance, no guesswork

QuotaDeck keeps the provider model deliberately open: `provider → accounts → windows[]`. A newly returned quota window is stored and rendered without waiting for a UI release.

![QuotaDeck dashboard with synthetic Claude, Codex, and Z.ai accounts](/screenshots/dashboard.png)

The native Linux package adds a desktop window, a user service, and a Cinnamon panel applet. The same loopback API remains available for scripts and integrations.

::: info Safe screenshot data
The documentation screenshots are generated by `make demo`. All account names and quota values shown above are synthetic.
:::
